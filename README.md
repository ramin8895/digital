# سایت آژانس دیجیتال مارکتینگ (Next.js + SCSS)

```
npm install
npm run dev   # http://localhost:3000
```

- رنگ‌ها و فاصله‌ها: بالای `app/globals.scss`
- متن‌ها و صفحات خدمات: `app/data.ts`
- صفحه اصلی: `app/page.tsx`
- ارسال فرم: `app/api/contact/route.ts` (ایمیل/CRM را آنجا وصل کنید)
- دامنه برای سئو: متغیر `NEXT_PUBLIC_SITE_URL`

قبل از انتشار: نام برند، آمار، نظرات، تیم، نمونه‌کار و قیمت‌ها نمونه‌ی ساختگی‌اند و باید واقعی شوند.
